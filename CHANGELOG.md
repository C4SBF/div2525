# Changelog

All notable changes to the Div2525 Framework will be documented in this file.

## [v1.1] - 2024-01-19

### Source-format import

This release establishes the Git-based source representation of the previously published
**Div2525 – Interoperability Framework for Smarter Buildings, version 1.1**.

The Markdown source in this repository was created from the original v1.1 PDF publication.
The intent of this import is to preserve the published v1.1 content while making the
Framework maintainable through GitHub issues, pull requests, review, and version control.

### Added

- Markdown source for the Div2525 Framework.
- Separate source files for:
  - Preface
  - Introduction
  - 25.25.00 – Master System Integration Requirements
  - 25.25.10 – Purpose of Interoperation
  - 25.25.20 – Operating Roles & Responsibilities
  - 25.25.30 – Information Delivery
  - 25.25.40 – Digital Applications
  - 25.25.50 – Orchestration
  - 25.25.60 – Data Governance
  - 25.25.70 – Control Systems
  - 25.25.80 – Physical Elements
  - 25.25.90 – Networking
  - 25.25.95 – Cybersecurity
  - Appendix 25.25.41 – Grid Interactivity
- Framework figures and supporting assets required by the Markdown source.
- A navigable `framework/README.md` table of contents.

### Changed

- Converted the original PDF layout into Markdown suitable for source control and review.
- Removed publication-only formatting such as page headers, footers, page numbers, and
  PDF table-of-contents artifacts.
- Converted headings, lists, callouts, and tables into equivalent Markdown structures
  where practical.
- Preserved the wording and section numbering of the published v1.1 Framework.

### Not changed

No substantive technical, normative, editorial, or policy changes to the Div2525
Framework were intended as part of this source-format import.

The original v1.1 PDF remains the historical published artifact for this release and is
provided as a GitHub Release asset.
